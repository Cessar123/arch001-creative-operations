# ARCH-001 Creative Operations

> **ARCH-001@Es0314es · ST-CAST-3D · [3/6/9/5/7 | 1/1]**

**ARCH-001 Creative Operations** هو مركز إنتاج لعالم الرسوم المتحركة **Bashosha City**. يجمع المنصة الإبداعية، وسجل الشخصيات، وخريطة الأحياء، وتعريفات السكن والعمل، وشات إنتاج يحافظ على استمرارية الشخصيات من دون انجراف بصري أو سردي.

**المنصة الحية:** [crearchbot-mthmrq9b.manus.space](https://crearchbot-mthmrq9b.manus.space)

## ما الذي يوفره المشروع؟

| القدرة | ما الذي تحققه؟ | الملف المرجعي |
| --- | --- | --- |
| غرفة العمليات | عرض خريطة الماستر، الأحياء، الكاست، وحالة كل DNA LOCK. | `client/src/pages/Home.tsx` |
| سجل المدينة | يحدد الدور، العائلة، السكن، العمل، الحي، الحالة، والقيد البصري لكل شخصية. | `shared/arch001.ts` |
| شات الإنتاج | ينشئ بطاقات مشاهد وحلقات وبروموهات مع قواعد منع الانجراف. | `server/arch001Engine.ts` |
| واجهة tRPC | تكشف مسار `arch001.chat` للواجهة في عقد Typed واحد. | `server/routers.ts` |
| التحقق | اختبارات لحارس الاستمرارية، والراوتر، وسلوك الدردشة. | `server/*.test.ts` |

## قواعد العالم غير القابلة للتجاوز

تتحرك الإنتاجات في هذا الترتيب فقط:

```text
Original Jewel → System Jewel → City → Cards → Episodes
```

العبارة `[3/6/9/5/7 | 1/1]` هي مرساة تنظيمية للعالم وليست بديلًا عن سجل الشخصيات. المصدر البرمجي للحقائق هو `shared/arch001.ts`؛ ويجب عدم اختراع عائلة أو عمر أو علاقة أو زي أو وجه جديد لشخصية مقفلة.

| الحالة | معناها الإنتاجي |
| --- | --- |
| `LOCKED` | الهوية البصرية والسردية معتمدة؛ لا تغيّر الوجه أو العمر أو الزي أو العائلة. |
| `READY` | الشخصية مسجلة وجاهزة، لكن شيت DNA LOCK البصري ما زال مطلوبًا قبل قفلها. |
| `PENDING` | لا يجوز توليدها بصريًا حتى تصل بطاقة أو مرجع مستقل. |

للتعليمات التفصيلية التي يمكن تسليمها لمطور أو شات جديد، اقرأ [مرجع ARCH-001 التشغيلي](ARCH001_REFERENCE.md).

## التشغيل المحلي

يتطلب المشروع **Node.js 22+** و**pnpm**. بعد نسخ المستودع، ثبّت الحزم ثم شغّل بيئة التطوير:

```bash
pnpm install
pnpm dev
```

تحتاج وظائف تسجيل الدخول، قاعدة البيانات، والشات الذكي إلى متغيرات بيئة الخادم التي تزودها منصة Manus في النسخة المستضافة. لا تضع مفاتيح الذكاء الاصطناعي أو مفاتيح OAuth في `client/` أو في المستودع.

| الأمر | الغرض |
| --- | --- |
| `pnpm check` | فحص TypeScript بلا توليد ملفات. |
| `pnpm test` | تشغيل اختبارات Vitest. |
| `pnpm build` | بناء العميل والخادم للإنتاج. |
| `pnpm start` | تشغيل الحزمة المبنية. |

## اختبار استمرارية ARCH-001

أرسل هذا المثال إلى الشات أو شغّل التحقق في بيئة تم ضبط متغيراتها:

```text
[001-DIR] ST-CAST-3D — CAST: شمندي، جوري، عيد — LOCATION: D02 — FUNCTION: مشكلة صباحية كوميدية. اكتب بطاقة مشهد قصيرة فقط.
```

الإخراج السليم يحافظ على شمندي كمرساة عائلية، وجوري كطفلة، وعيد كشخصية مقالب؛ ولا يبدّل الوجوه أو الأعمار أو الأزياء أو الروابط العائلية. اختبارات الحارس البرمجية موجودة في `server/arch001Engine.test.ts`، ويوجد تحقق حي مساعد في `scripts/verify_arch001_live_chat.mjs`.

## إضافة أو تحديث شخصية

ابدأ دائمًا من السجل، لا من مولد الصور. أضف المعرف، الدور، العائلة، السكن، العمل، الحي، والحالة و`visualLock` في `shared/arch001.ts`. بعد اعتماد المرجع البصري، حدّث الحالة إلى `LOCKED` واكتب أو حدّث اختبارًا يمنع الخلط بينها وبين قريب أو شخصية مشابهة. شيتات DNA LOCK هي مراجع إنتاجية مستقلة ويجب أن تبقى متسقة مع السجل.
